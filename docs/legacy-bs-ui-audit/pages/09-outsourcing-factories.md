# 09 外发厂

![外发厂](../screenshots/09-outsourcing-factories.png)

## 页面信息

1. 页面名称：外发厂。
2. 菜单位置：基础设置 / 外发厂。
3. URL：`/basic-settings/outsource-factories`。
4. 主要用途：维护外发工厂名称、简称、联系人、联系电话、状态和备注，供外发排单引用。
5. 主要角色：外协管理员、生产主管、采购/跟单人员、系统管理员。
6. 顶部筛选：按名称、简称或备注搜索。
7. 主要按钮：新增外发厂；有数据时预期提供编辑等行操作。
8. 表格字段：名称、简称、状态、联系人、联系电话、备注、操作。
9. 表格行为：可横向滚动；审计时列表为空，未观察到固定列和分页。

## 新增外发厂弹窗

![新增外发厂](../screenshots/09a-outsourcing-factory-add-dialog.png)

10. 点击新增打开弹窗。
11. 字段：名称、简称、联系人、联系电话、备注。按钮：关闭、取消、保存外发厂。
12. 典型流程：搜索确认 → 新增外发厂 → 填写联系人和备注 → 保存 → 排单时选择外发厂；停用后继续保留历史引用。
13. UI/UX 问题：空态重复新增按钮；表单未直接显示说明中提到的状态；联系电话缺少格式提示；未展示地区、能力、交期或质量信息。
14. 值得保留：停用不破坏历史引用；联系人和备注满足最小可用资料；简称适合高密度排单表。
15. 建议重新设计：增加地区、擅长品类、产能、交期和质量等级；明确状态控件；提供引用数量和停用影响；把联系人扩展为可维护的联系人列表。
