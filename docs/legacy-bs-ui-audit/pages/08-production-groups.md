# 08 生产组

![生产组](../screenshots/08-production-groups.png)

## 页面信息

1. 页面名称：生产组。
2. 菜单位置：基础设置 / 生产组。
3. URL：`/basic-settings/production-groups`。
4. 主要用途：维护内部生产组、简称、生产地点、排序和状态，供排单稳定引用。
5. 主要角色：生产主管、生产计划员、系统管理员。
6. 顶部筛选：按名称、简称或备注搜索。
7. 主要按钮：新增生产组；有数据时预期提供编辑等行操作。
8. 表格字段：名称、简称、生产地点、状态、排序、备注、操作。
9. 表格行为：可横向滚动；审计时列表为空，未观察到固定列和分页。

## 新增生产组弹窗

![新增生产组](../screenshots/08a-production-group-add-dialog.png)

10. 点击新增打开弹窗。
11. 字段：名称、简称、生产地点、排序、备注。生产地点选项为已维护的工厂。按钮：关闭、取消、保存生产组。
12. 典型流程：新增生产组 → 选择生产地点 → 设置排序 → 保存 → 在生产排单中出现并接收队列。
13. UI/UX 问题：空页面同时出现两个新增入口；弹窗说明提到可停用，但新增表单未显示状态字段；排序为裸数字，缺少拖拽或位置预览。
14. 值得保留：稳定 ID、停用不丢历史、生产组与生产地点分离、可配置排序。
15. 建议重新设计：列表提供拖拽排序和产能摘要；明确启用状态；显示关联排单数及停用影响；空态只保留一个主操作。
