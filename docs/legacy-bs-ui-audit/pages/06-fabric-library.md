# 06 面料库

![面料库](../screenshots/06-fabric-library.png)

## 页面信息

1. 页面名称：面料库。
2. 菜单位置：基础设置 / 面料库。
3. URL：`/basic-settings/fabrics`。
4. 主要用途：维护可复用面料的静态资料、供应商、采购单位、损耗率和单价。
5. 主要角色：面辅料管理员、采购员、报价员。
6. 顶部筛选：按名称、成分或供应商搜索。
7. 主要按钮：新增面料、编辑、删除。
8. 表格字段：面料名称、成分、净门幅、克重、默认损耗率、供应商、单价、采购单位、操作。
9. 表格行为：可横向滚动；未发现固定列和分页。

## 新增面料弹窗

![新增面料](../screenshots/06a-fabric-add-dialog.png)

10. 点击新增打开弹窗。
11. 字段：面料名称、成分、净门幅 cm、克重 gsm、默认损耗率、供应商、单价、采购单位（千克/米）。按钮：关闭、取消、保存面料。
12. 典型流程：搜索确认是否已有面料 → 新增静态资料 → 选择或输入供应商 → 设置采购单位与默认损耗 → 保存 → 报价时引用并形成快照。
13. UI/UX 问题：单位分散在标签和下拉中；同名面料的规格区分能力不足；删除入口直接暴露；没有批量导入、合并重复项或停用状态。
14. 值得保留：报价快照与基础库分离；供应商可复用历史值；采购单位支持 kg/m；损耗率作为默认值而非强制联动。
15. 建议重新设计：增加编码、别名、状态、更新时间和重复检测；单位采用统一的数值+单位控件；支持批量导入与停用；在引用时显示基础库版本和快照差异。
