# 03 生产排单

![生产排单总览](../screenshots/03-production-scheduling.png)

## 页面信息

1. 页面名称：生产排单。
2. 菜单位置：一级菜单“生产排单”，无二级菜单。
3. URL：`/production-scheduling`；生产组队列和物料运输均在同一路由内切换状态。
4. 主要用途：查看生产组负荷、待生产款数、队尾日期、未排订单与异常，并维护订单物料到仓信息。
5. 主要角色：生产计划员、生产主管、跟单/理单员、物流协调员。

## 筛选与操作

6. 顶部筛选：搜索订单、款号、款名或客户；视图切换为生产组总览、未排订单、异常。
7. 主要按钮：物料与运输、生产组总览、未排订单、异常、生产组卡片；单组队列中有返回总览、编辑、结束。

## 主展示与队列表格

8. 总览以生产组卡片显示名称、状态、当前款、待生产款数、预计排至日期。单组队列字段：顺序、款号 / 客户、排单数量、平均日产、工作日、开始、结束、休息、物料 / 物流、状态、操作。
9. 总览无分页；单组队列存在横向滚动和粘性区域，未观察到分页。

## 关键状态与弹窗

### 物料与运输

![物料与运输弹窗](../screenshots/03b-production-material-transport-dialog.png)

- 字段：供应枢纽、面料到枢纽日期、辅料到枢纽日期、备注。
- 说明明确“两类物料都到达供应枢纽后才形成物料齐套日”。
- 按钮：关闭、取消、保存。

### 生产组队列

![生产组队列](../screenshots/03c-production-group-queue.png)

- 从生产组卡片进入单组队列，显示队尾日期和每条排单的日期、效率、物料及状态。
- 行操作包括编辑；未结束排单还提供结束。

## 典型操作流程

12. 查看生产组负荷 → 切换未排订单或异常 → 搜索目标订单 → 进入生产组队列 → 调整排单顺序/日期/产能 → 补充物料到仓信息 → 结束生产并推动后续队列。

## UI/UX 审计

13. 主要问题：总览和队列的层级切换缺少持久面包屑；异常原因只在状态附近简写；物料运输与具体订单/排单的对应关系不够明确；编辑和结束操作靠近，风险等级不清；生产组卡片未直接展示产能利用率或逾期量。
14. 值得保留：按生产组组织队列；队尾日期；未排与异常独立视图；物料齐套与运输信息进入排单决策；队列中同时显示数量、日产和工作日。
15. 建议重新设计：总览增加负荷率、逾期/风险数、产能趋势；使用主从布局保留生产组上下文；异常提供原因分类和快速筛选；把排单编辑做成时间轴或甘特视图，同时保留紧凑表格；危险的结束操作使用独立确认和影响预览。
