# 14 关账设置

![关账设置](../screenshots/14-closing-settings.png)

## 页面信息

1. 页面名称：关账设置。
2. 菜单位置：系统设置 / 关账设置。
3. URL：`/system-settings/closing-settings`。
4. 主要用途：维护新关账月份使用的默认销售产值税率和月度生产目标。
5. 主要角色：财务管理员、经营管理者、系统管理员。
6. 顶部筛选：无。
7. 主要按钮：新增月度目标、保存默认税率、新增目标、编辑、删除。
8. 表格字段：月份、总加工产值目标、内部加工产值目标、备注、操作。
9. 表格行为：可横向滚动；未发现固定列和分页。

## 新增月度目标弹窗

![新增月度目标](../screenshots/14a-closing-target-add-dialog.png)

10. 点击新增月度目标打开弹窗。
11. 字段：月份、总加工产值目标（RMB）、内部加工产值目标（RMB）、备注。按钮：关闭、取消、保存目标。
12. 典型流程：设置默认税率 → 保存 → 新增月份目标 → 输入总目标和内部目标 → 保存 → 关账中心创建月份时引用快照。
13. UI/UX 问题：“新增月度目标”和“新增目标”重复；默认税率单独保存，与页面其他配置保存模式不统一；金额输入缺少千分位和范围反馈；删除紧邻编辑。
14. 值得保留：税率只作为新月份默认值；金额口径明确为 RMB；一个月份只保留一条目标；区分总加工与内部加工目标。
15. 建议重新设计：统一一个新增入口；金额输入实时格式化；展示目标与实际完成对比；税率和目标分区使用明确的独立保存状态；删除前显示已被关账月份引用情况。
