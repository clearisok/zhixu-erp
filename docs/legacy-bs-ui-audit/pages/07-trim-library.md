# 07 辅料库

![辅料库](../screenshots/07-trim-library.png)

## 页面信息

1. 页面名称：辅料库。
2. 菜单位置：基础设置 / 辅料库。
3. URL：`/basic-settings/trims`。
4. 主要用途：维护辅料名称、规格、供应商、单位、损耗率和默认单价，供报价引用。
5. 主要角色：面辅料管理员、采购员、报价员。
6. 顶部筛选：按名称、规格或供应商搜索。
7. 主要按钮：新增辅料、编辑、删除。
8. 表格字段：辅料名称、规格、供应商、单位、默认损耗率、单价、操作。
9. 表格行为：可横向滚动；未发现固定列和分页。

## 新增辅料弹窗

![新增辅料](../screenshots/07a-trim-add-dialog.png)

10. 点击新增打开弹窗。
11. 字段：辅料名称、规格、供应商、单位、默认损耗率、默认单价。按钮：关闭、取消、保存辅料。
12. 典型流程：搜索已有辅料 → 新增/编辑基础资料 → 设置单位、损耗和单价 → 保存 → 品牌或报价中引用。
13. UI/UX 问题：单位为自由文本，易产生“个/只/粒”等不一致值；无停用状态、编码和分类；列表操作重复且删除风险突出。
14. 值得保留：报价用量不保存在基础库；规格、供应商与默认单价完整；报价引用后形成独立快照。
15. 建议重新设计：建立辅料分类和标准单位字典；增加编码、状态、最后价格日期和供应商维度；支持相似项合并；批量编辑损耗和单价。
