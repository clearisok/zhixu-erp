# 15 生产与运输

![生产与运输](../screenshots/15-production-transport-settings.png)

## 页面信息

1. 页面名称：生产与运输。
2. 菜单位置：系统设置 / 生产与运输。
3. URL：`/system-settings/production-infrastructure`。
4. 主要用途：维护生产日历、生产地点、供应枢纽、枢纽到工厂的路线及运输方式。
5. 主要角色：生产管理员、物流管理员、生产计划员、系统管理员。
6. 顶部筛选：无。
7. 主要按钮：新增日历、新增地点、新增枢纽、新增路线、新增方式，以及各实体的编辑。
8. 主展示字段：日历名称/工作周/例外日期；地点名称/国家代码/封样提前；枢纽与路线名称；运输方式名称/自然日/路线。页面为分区卡片，无标准表格。
9. 滚动与分页：纵向滚动；无固定区域和分页。

## 关键弹窗

所有实体共用标题“编辑生产与运输设置”，字段随入口变化。

| 状态 | 主要字段 | 截图 |
| --- | --- | --- |
| 新增生产日历 | 名称、每周工作日、例外日期 JSON、备注 | [截图](../screenshots/15a-production-calendar-add-dialog.png) |
| 新增生产地点 | 名称、国家代码、生产日历、产前样提前天数、备注 | [截图](../screenshots/15b-production-site-add-dialog.png) |
| 新增供应枢纽 | 名称、备注 | [截图](../screenshots/15c-supply-hub-add-dialog.png) |
| 新增运输路线 | 名称、供应枢纽、生产地点、备注 | [截图](../screenshots/15d-transport-route-add-dialog.png) |
| 新增运输方式 | 名称、路线、运输自然日、备注 | [截图](../screenshots/15e-transport-method-add-dialog.png) |

10. 各新增/编辑均使用同一居中弹窗。
11. 通用按钮：关闭、取消、保存。
12. 典型流程：建立生产日历 → 建立生产地点并关联日历 → 建立供应枢纽 → 连接枢纽与地点形成路线 → 为路线建立不同运输方式和时长 → 排单根据物料齐套和开工日期推荐运输。
13. UI/UX 问题：五类实体同页混排且弹窗标题完全相同；依赖关系只靠文字和下拉体现；工作日和例外日期要求输入数字/JSON，对业务用户不友好；路线缺少可视化；卡片操作多但无搜索。
14. 值得保留：日历、地点、枢纽、路线、运输方式实体分离；特殊日期优先于周模板；运输时长使用自然日；系统能推荐满足时效的最慢方式。
15. 建议重新设计：以依赖关系图或分步向导呈现；日历使用周选择器和可视日期例外；每种实体使用准确弹窗标题；路线提供起点终点可视化；增加启停状态、引用数量和影响分析。
