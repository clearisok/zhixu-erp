# 16 数据管理

![数据管理](../screenshots/16-data-management.png)

## 页面信息

1. 页面名称：数据管理。
2. 菜单位置：系统设置 / 数据管理。
3. URL：`/system-settings/data-management`。
4. 主要用途：备份、导入或重置本地测试业务数据。
5. 主要角色：系统管理员、测试环境维护人员。
6. 顶部筛选：无。
7. 主要按钮：导出测试数据、导入测试数据、重置全部本地业务数据。
8. 主表格：无；页面分为“本地数据备份”和“重置本地业务数据”两个危险级别不同的卡片区。
9. 滚动与分页：无表格、无分页。
10. 关键弹窗：本次未点击导入和重置，避免触发文件选择、覆盖或重置流程；因此不记录确认弹窗字段。
11. 页面可见按钮已完整记录；导入预计需要文件选择，重置属于最高风险操作。
12. 典型流程：先导出备份 → 选择测试数据文件导入 → 验证数据；仅在明确二次确认和已有备份时执行全部重置。
13. UI/UX 问题：备份、导入和不可逆重置位于同页且距离较近；“测试数据”与“全部本地业务数据”范围表述不完全一致；缺少最近备份时间、文件内容预检、影响统计和恢复点。
14. 值得保留：本地数据管理入口集中；重置按钮单独放在危险区；页面说明强调数据只在当前浏览器环境。
15. 建议重新设计：把备份/恢复与重置分成两个标签；导入前显示版本、记录数和差异预览；重置要求输入环境名并显示影响对象；自动生成可恢复快照；显示最近备份和导入日志。
