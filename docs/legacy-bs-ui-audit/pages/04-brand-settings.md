# 04 品牌设置

![品牌设置](../screenshots/04-brand-settings.png)

## 页面信息

1. 页面名称：品牌设置。
2. 菜单位置：基础设置 / 品牌设置。
3. URL：`/basic-settings/brands`。
4. 主要用途：维护品牌、启停状态，以及品牌级汇率、固定辅料和其他费用默认值。
5. 主要角色：系统管理员、报价主管、基础资料管理员。
6. 顶部筛选：品牌名称搜索。
7. 主要按钮：新增品牌、编辑、删除。
8. 表格字段：品牌名称、状态、默认汇率、默认辅料、默认其他费用、客户业务员、操作。
9. 表格行为：可横向滚动；未发现固定列和分页。

## 新增品牌弹窗

![新增品牌](../screenshots/04a-brand-add-dialog.png)

10. 点击新增打开居中弹窗。
11. 字段：品牌名称、状态、默认 USD/CNY 汇率、默认其他费用名称、默认其他费用金额、固定辅料；固定辅料从辅料库搜索添加。按钮：关闭、取消、保存品牌。
12. 典型流程：搜索品牌 → 新增或编辑 → 设置品牌默认参数和固定辅料 → 保存；删除用于清理不再使用的品牌。
13. UI/UX 问题：标题区和列表区重复出现“新增品牌”；删除紧邻编辑；默认值的“回退系统值”虽有意义，但层级关系只靠文字表达；列宽偏大且无固定首尾列。
14. 值得保留：品牌级默认值、固定辅料引用、客户业务员数量、启停状态和回退语义。
15. 建议重新设计：只保留一个主新增按钮；用继承关系图或“来源”标签显示系统/品牌值；危险操作移入更多菜单；增加停用优先于删除的引导和引用影响提示。
