# 05 客户业务员设置

![客户业务员设置](../screenshots/05-customer-salespeople.png)

## 页面信息

1. 页面名称：客户业务员设置。
2. 菜单位置：基础设置 / 客户业务员设置。
3. URL：`/basic-settings/customer-salespeople`。
4. 主要用途：维护客户业务员、归属品牌及覆盖品牌默认值的个人报价参数。
5. 主要角色：系统管理员、报价主管、业务管理者。
6. 顶部筛选：按姓名或品牌搜索。
7. 主要按钮：新增客户业务员、编辑、复制、删除。
8. 表格字段：客户业务员、归属品牌、状态、默认汇率、默认辅料、默认其他费用、操作。
9. 表格行为：可横向滚动；未发现固定列和分页。

## 新增客户业务员弹窗

![新增客户业务员](../screenshots/05a-customer-salesperson-add-dialog.png)

10. 点击新增打开弹窗。
11. 字段：客户业务员姓名、归属品牌、状态、默认 USD/CNY 汇率、默认其他费用名称和金额、固定辅料。按钮：关闭、从辅料库添加、取消、保存客户业务员。
12. 典型流程：选择品牌 → 新增业务员 → 仅在必要时覆盖品牌默认配置 → 保存；复制用于建立相近配置。
13. UI/UX 问题：个人默认值、品牌默认值、系统默认值的优先级需要阅读说明才能理解；新增按钮重复；复制与编辑、删除并排，误操作风险较高。
14. 值得保留：个人配置优先于品牌的业务规则；复制能力；归属品牌和启停状态。
15. 建议重新设计：在表格中显示每项默认值的来源；弹窗分为基本信息与覆盖设置，并默认折叠覆盖项；复制后明确要求修改姓名；危险操作归入二级菜单。
