# 12 用户权限

![用户权限](../screenshots/12-user-permissions.png)

## 页面信息

1. 页面名称：用户权限。
2. 菜单位置：系统设置 / 用户权限。
3. URL：`/basic-settings/user-permissions`。
4. 主要用途：查看用户、账号、角色和状态，并按角色检查完整权限键目录。
5. 主要角色：系统管理员、安全管理员、审计人员。
6. 顶部筛选：无。
7. 主要按钮：恢复默认权限、权限详情、切换为此账号；详情区可选择角色和状态，并用权限复选框展示/配置权限。
8. 用户表字段：姓名、账号、角色、状态、操作。
9. 表格行为：可横向滚动；未发现固定列和分页。

## 权限详情

![用户权限详情](../screenshots/12d-user-permission-detail.png)

10. 点击“权限详情”在当前页面下方展开，不打开弹窗或新页面。
11. 详情字段：用户姓名/账号、角色、状态、角色权限计数；权限按报价、版本、成本、估算、订单、排单、关账、基础设置、生产基础资料、权限管理、系统审计分组。每项显示名称、说明和权限键。管理员当前显示 43/43 项。
12. 典型流程：选择用户 → 查看权限详情 → 调整角色或单项权限 → 验证账号视角；“恢复默认权限”和“切换为此账号”均属于高影响操作，本次未触发。
13. UI/UX 问题：43 项权限纵向铺开，难以比较角色差异；用户表和权限编辑区距离很远；权限键对业务管理员过于技术化；缺少批量全选/清空、差异视图和搜索；高风险“恢复默认”位置显眼但影响范围说明不足。
14. 值得保留：业务组件按权限键而非角色名判断；权限分组、描述和稳定权限键完整；用户与角色关系清晰；可切换账号做验收。
15. 建议重新设计：采用用户/角色主从布局；支持权限搜索、按组全选、角色对比和“仅显示差异”；技术键次级显示；高风险操作增加影响预览；提供只读权限摘要与变更审计。
