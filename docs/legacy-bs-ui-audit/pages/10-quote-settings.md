# 10 报价设置

![报价设置](../screenshots/10-quote-settings.png)

## 页面信息

1. 页面名称：报价设置。
2. 菜单位置：系统设置 / 报价设置。
3. URL：`/system-settings/quote-settings`。
4. 主要用途：维护报价系统回退值、制作国家预设、默认其他费用和默认工序说明。
5. 主要角色：系统管理员、报价主管。
6. 顶部筛选：无。
7. 主要按钮：加工币种 CNY/USD 切换、新增预设、删除预设、保存报价设置。
8. 主表格：无；页面为四个连续配置区。
9. 滚动与分页：纵向长表单；无固定区和分页。

## 字段与操作

10. 页面内直接编辑，无独立弹窗。
11. 字段包括：系统默认 USD/CNY 汇率、默认成本加成率、默认加工币种；新报价默认预设；每个制作预设的名称、制作国家、加工币种、成本加成率、是否默认带出运费、运费名称与金额；默认其他费用名称和金额；默认工序说明。按钮包括新增/删除预设与页面底部保存。
12. 典型流程：维护系统回退参数 → 建立中国/柬埔寨等制作预设 → 选择新报价默认预设 → 设置费用与工序说明 → 保存；新报价形成快照，既有报价不回写。
13. UI/UX 问题：页面过长且唯一保存按钮在底部；多个预设重复大量字段；删除预设紧邻编辑区；币种使用自制分段按钮，状态不够突出；继承和快照规则分散在说明文字中。
14. 值得保留：设置只影响新建快照、不回写历史；制作国家预设把国家、币种、加成率与运费组合起来；系统回退值清晰。
15. 建议重新设计：预设改为可折叠卡片或表格+详情抽屉；页面顶部显示未保存状态并固定保存栏；对删除显示引用影响；用“生效范围/来源”摘要解释系统、品牌和个人层级。
