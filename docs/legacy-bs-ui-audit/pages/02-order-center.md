# 02 订单中心

![订单中心](../screenshots/02-order-center.png)

## 页面信息

1. 页面名称：订单中心。
2. 菜单位置：一级菜单“订单中心”，无二级菜单。
3. URL：`/order-center`；详情为 `/order-center/detail?id={orderId}`；新建为 `/order-center/new`。
4. 主要用途：以“一行一张单款订单”管理客户订单、数量、价格、交期以及生产和关账状态。
5. 主要角色：业务员、跟单/理单员、订单主管、生产计划员、管理者。

## 筛选与操作

6. 顶部筛选：搜索订单号、客户 PO、款号、款名或客户；订单状态（全部/草稿/已确认/执行中/已取消）；订单类型（全部/加工/经销）。
7. 主要按钮：页面设置、新建订单、打开订单；详情页另有返回列表、翻单、保存草稿、取消订单、调整数量、调整价格、添加交期、上传附件、进入排单中心、进入关账中心、维护物料与运输。

## 主表格

8. 字段：订单号、款式图、款号、客户 / PO、类型、制作国家、有效数量、当前工价、当前销售价、最近 / 最终交期、理单员、订单 / 生产 / 关账、更新时间、操作。
9. 表格行为：桌面结构存在横向滚动与粘性区域；未观察到分页。767px 视口改为订单卡片列表，保留编号、款号、客户、数量、交期和状态。

## 关键状态与弹窗

### 订单详情

![订单详情](../screenshots/02d-order-detail.png)

- 顶部摘要：款号、类型、状态、有效数量、工价、销售价、最近/最终交期。
- 主要字段：款号、款式名称、客户、客户 PO、品牌、制作国家、原始数量、客户要求、订单类型、下单日期、业务员、理单员、备注。
- 下方包含当前价格、交期、价格历史、数量历史、执行资料快照、附件、排单摘要、关账状态、物料运输和操作记录。

### 新建订单

![新建订单](../screenshots/02n-new-order.png)

- 新建使用完整工作区，系统预显示订单号。
- 主要字段除订单基础资料外，还包括初始销售价、初始工价、加工币种、汇率依据。
- 离开空白新建页也会出现未保存拦截；提供继续编辑、不保存并返回、保存并返回。

### 列表页面设置

![订单列表页面设置](../screenshots/02p-order-page-settings-dialog.png)

- 可设置订单号、款式图、款号/款名、客户/PO、类型、制作国家、数量、工价、销售价、交期、理单员、状态、更新时间和操作列宽。
- 按钮：恢复默认、取消、保存设置。

## 典型操作流程

12. 搜索订单 → 打开订单 → 核对客户/款式/数量/价格 → 安排多交期 → 确认订单 → 进入排单 → 跟进完成数量 → 进入关账；翻单用于从已有订单创建新单。

## UI/UX 审计

13. 主要问题：详情页把商务、生产、物流、关账、附件和日志全部堆叠在一页；“保存草稿”与多种局部调整弹窗并行；列表宽度大；新建空白页一进入就被视为有修改；订单状态、生产状态和关账状态组合在一列，扫描成本高。
14. 值得保留：单款订单模型；价格与数量历史；多交期；排单、关账和物料运输摘要；从订单直接进入下游模块；离开前的未保存保护。
15. 建议重新设计：详情拆分为“概览、商务资料、交期与数量、生产与物流、财务与关账、历史”；顶部保留统一状态与主操作；列表把三类状态拆分或使用结构化状态矩阵；新建页在首次实际输入后再触发未保存保护；加强跨模块跳转的返回上下文。
