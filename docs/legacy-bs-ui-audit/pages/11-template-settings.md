# 11 模板设置

![模板设置](../screenshots/11-template-settings.png)

## 页面信息

1. 页面名称：模板设置。
2. 菜单位置：系统设置 / 模板设置。
3. URL：`/basic-settings/templates`。
4. 主要用途：维护客户报价单 Excel 模板版本、默认模板和支持的占位符字段。
5. 主要角色：系统管理员、报价主管、模板维护人员。
6. 顶部筛选：无。
7. 主要按钮：支持字段、创建模板版本；模板卡片操作为下载、设为默认、试导出、复制。
8. 主列表字段：模板名称/文件名、类型、版本、状态、更新时间、操作；当前以卡片/伪表格呈现而非语义表格。
9. 滚动与分页：无横向表格滚动；未观察到分页。

## 关键弹窗

### 支持字段

![模板支持字段](../screenshots/11a-template-supported-fields-dialog.png)

- 按报价基础信息、报价版本、价格版本、面料、辅料、加工、其他费用、汇总、客户确认、款式图分组展示占位符。
- 明确动态重复行和禁止内部字段 `{{estimate.*}}`；按钮为两个关闭入口。

### 创建模板版本

![创建模板版本](../screenshots/11b-template-create-dialog.png)

- 字段：模板名称、Excel 模板文件。
- 按钮：关闭、取消、验证并创建；上传不会覆盖旧版本。

12. 典型流程：查看支持字段 → 准备 Excel → 创建模板版本并验证 → 试导出 → 设为默认；旧版本继续保留。
13. UI/UX 问题：支持字段弹窗信息量大且缺少搜索/复制按钮；模板卡片看似表格但对齐弱；“下载/试导出/复制/设为默认”并列，主次不清；创建弹窗文件选择控件不够可见。
14. 值得保留：模板版本化、不覆盖旧文件、上传前验证、试导出、占位符分组和禁止字段规则。
15. 建议重新设计：支持字段增加搜索、单击复制和示例；模板列表使用标准表格并突出默认版本；创建流程分为上传、验证结果、发布三步；显示模板引用次数和最近试导出结果。
