## 权限与异步边界

- 查看需要order.view与schedule.view，写入另需schedule.edit；前端按钮不是授权，后端fresh校验保持，不授金额权限。
- 只读或冻结后展示已保存事实，保留的未保存草稿明确说明尚未应用。关闭、换订单、会话替换和A→B→A都以layout session及具体Drawer实例隔离迟到响应，包括401。
- 未保存输入、提交中、结果未知均接入原导航保护。计划、实际进度和物流操作共享未决槽，不能在另一弹窗绕过未知结果。
- 订单排单抽屉不等待可选tracking读取才出现；读取失败只在该部分提示。关闭旧抽屉后的迟到结果不能覆盖新抽屉或使新会话失效。
