# 正式Server关账调整界面（Gate8G2e）

2026-10-27。依据D169–D172及[具体修订草图批准](../tasks/completed/2026-10-27-closing-adjustment-ui-approval.md)，复用既有年度读取、月份计划、财务快照及原请求协议，不引入价格、数量或财务的第二权威。

## 页面与操作

`/closing-center`和`/closing-center/detail`先选择authority再挂载owner。Server候选仍要求显式snapshot、可信session及closing/order/schedule查看权；默认Browser路径、Repository、key、数据与旧环境不变。导航只有符合已有开放范围和权限才出现。

全年十二个月只显示成衣销售CNY、加工USD。范围全部/内制/外发/未分配、制作状态和空格且搜索同时作用于明细及未分页汇总；表格分页不改变合计。制作状态来自真实完成事实，只作参考。未知价格/税率不补0，无金额权限不输出金额。开放月当前采用价参考与冻结月manifest快照明确区分。

调整弹窗读取整单月份及生产只读资料，部分数量或整单调月。整单包括当前筛选隐藏的全部月份、颜色、内外发与未分配。固定底栏预览后明确保存，原因必填；不提供自由输入价格/工价。两项产值差异只对严格预览的受影响月及数量变化的待分月，用原精确金额函数和已采用价格/显式税率说明，不重算无关冻结月，不构成财务采用。确认/锁定月由原服务拒绝普通调月。

月份管理沿用原财务command：新期间税率留空并显式确认；开放月明确选择有权渠道采用完整月份计划，随后确认/锁定；重开带原因。不重新提供逐单逐色手填关账入口。已冻结生产更正保护和不可变快照不变。

## 身份、金额与未知结果

页面与弹窗均绑定当前session/上下文owner；年份、范围、身份或权限变化后晚响应不生效。有效读取401使session失效，全年读取403清除已展示旧金额。搜索输入不随读取代次卸载，保持焦点及中文输入。

新月份与旧financial共用原请求控制器，保存并读回原命令后才POST，未知只核对原ID，明确unknown后用户可重试原ID；已知终态才释放。页面独立扫描当前actor的两个既有pending地址，刷新不POST。恢复入口不依赖可见订单或编辑权；损坏字节保留并阻断新操作。原请求及未保存输入有离开保护。

执行方名称只用保存executorBasis及精确资源hash匹配资料；当前执行方变化时显示原内/外发历史提示，不能把新归属冒充原记录。当前UI不提供执行方匹配命令：演示预先经服务显式匹配，不能称该完整操作已向用户开放。
