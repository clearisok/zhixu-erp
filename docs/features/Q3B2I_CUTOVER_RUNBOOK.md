## Failure truth table

| Event | Database truth | Required action |
| --- | --- | --- |
| Frozen frontend replacement fails | No import write | Do not stop the DB writer; repair the frontend path. No freeze evidence exists yet. |
| Freeze evidence creation or validation fails | No import write | Do not stop the DB writer; keep frozen frontend or safely abort before writer freeze. Do not claim Browser freeze proven. |
| Independent writer freeze fails | No import write | Keep Browser frozen; no automatic writer restart. |
| Fresh export fails | No import write | Keep Browser frozen; stop. |
| Canonical Preview fails | No import write | Keep Browser frozen; stop. |
| Disposable rehearsal fails | No import write | Keep Browser frozen; stop. |
| Final rollback backup or manifest fails | No import write | Keep Browser frozen; stop. |
| Guarded VerifyOnly fails | No import write | Keep Browser frozen; stop. |
| Evidence second-copy or destination hash verification fails | No import write | Keep Browser frozen; do not request import Execute authorization. |
| Execute transaction fails before COMMIT | Import rolled back | Keep Browser frozen; stop; retain FAILED D-091 evidence. |
| COMMIT outcome unknown | Unknown | Keep Browser frozen; no retry or restore; investigate ledger, rows and D-091 evidence. |
| COMMITTED but readback unverified | Committed, not validated | Keep Browser frozen; no retry or claim of rollback; investigate. |
| COMMITTED/readback PASS but Server deployment or smoke fails | Imported rows remain | Keep Browser frozen; do not reopen Browser writable authority or auto-restore. |

Restoring the backup or returning to Browser writable authority always requires new user authorization and a separately reviewed reconciliation plan.
