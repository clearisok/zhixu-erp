## 创建与维护

合同类正式 SO 仅由可信艾诺科销售合同接纳产生；加工类由独立下单批次消费产生。合同/批次唯一身份和幂等保持，同报价可服务多张真实订单。两类均无负责人或认领前置。新业务来源只选报价；认领、转交、合同前准备、独立翻单和公开归一写入口已退役，旧数据可查。

订单详情“维护来源”打开最大1280px的 Foundation 分步 Modal：搜索分页选报价（空格分词为 AND）→ 同一 Quote/Revision 选择确认 PriceVersion 并匹配颜色 → 预览后采用。只用确认值，不提供自由金额输入。首次保存形成不可变产品/商业版本。已有成交条件后的改配只能在报价中心按调价权限执行，不能重存来源覆盖议价。

加工来源由消费批次固定，订单中只读工价。报价上下文改配的预览和实际提交均拒绝加工类；原请求重放只可读取原提交结果，不产生新采用。客户再次真实下单需新批次，不能以 Quote ID 全局去重。

2026-10-20 Gate5工程候选在合同首次选择步骤添加紧凑“创建报价”：进入原Server新建页只读核实上下文，再明确创建经销草稿，沿用原Editor。已采用、完成/取消、历史重复和加工已消费订单不能借此改来源。创建时保存的原SO/合同/款号/数量/交期参考独立于后续商业采用；创建和返回均不改变订单来源或成交价，确认报价后仍需在原三步流程明确选择。客户端UUID/指纹不作为可信事实，品牌/客户不按名字建关联。具体API、回执及工程范围见[报价说明](QUOTE_CENTER.md)与[Gate5](../tasks/active/server-convergence-gate5-2026-10-20.md)，不代表合并或部署。

## 身份、价格和历史

稳定订单颜色 ID 由订单与规范颜色身份确定，数量/交期改变不换身份；同名不唯一阻断，新增/改名待匹配，删除颜色保留历史。原 source hash 是证据，不是长期价格关联键。

0015 商业版本、0027 产品快照、0028 颜色明细/head/审计按事务追加。快照保留精确产品、方案及原附件 ID，但不冒称已冻结附件二进制或独立技术包。来源维护不改订单 UUID、创建历史、来源绑定、采购、物料、排单或数量。

CCT 存在即为报价确认权威，空值不回退；零有效。订单价格独立，修改共享报价不改已采用版本。旧统一价只标为历史全单依据，不用当前报价补造原颜色分配。颜色汇总同时区分方案、实际价格和币种，见 [商业版本](ORDER_COMMERCIAL_VERSIONS.md)。

## API 与权限

`GET /api/v1/sales-orders/:id/business-source` 读取；`POST /preview` 预览首次采用；POST 主路径提交。`/api/v1/quotes/:quoteId/orders/:id/business-source` 供报价上下文改配。可信 session、同源写边界、fresh grants、领域及金额查看/修改权限、来源指纹、订单 CAS、请求幂等、命令暂停与冻结共同保护；不能仅依赖预览或按钮隐藏。

产品原始快照含成本，仅供内部持久化，API 输出白名单元数据及独立授权价格。旧商业 POST/preview、认领/转交/血统 PATCH、准备与归一公开写入口返回410。旧权限键、记录及恢复测试仅作兼容，不因此修改真实账号或重新开放业务入口。
