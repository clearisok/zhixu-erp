# 关账月份的可信来源复核（D-174）

2026-10-27；实施D169已经批准的来源数量/颜色显式复核。只扩展既有未定价月份版本和原请求协议；没有新价格、财务数量入口或来源采集。

## 命令与证据

同一`/api/v1/closing/month-plans/preview|commands|commands/:requestId`增加`reconcile_source`，需要`closing.edit`及既有读取权限。输入只有物理SO、预计月份版本、只读获得的当前Source fingerprint、原因、原片段减量/删除和新颜色增量；不得输入月份、执行方、价格、税率或替代来源总量。合计100项/16KiB、原版本2000行/256KiB、可信颜色2000项/证据256KiB，超限明确拒绝。

读取增加无金额`observedSource`，保存时在既有全局/订单/来源锁下重读当前可信事实。fingerprint未变化不造新版本；预览后再次变化、CAS竞争和坏原请求均拒绝。普通move/match继续在Source变化时阻断，不能借新动作绕开。

## 数量和历史边界

- 每个可信当前颜色和全SO量必须精确相等；不完整、歧义、未知或超精度来源不能猜测、截断或补零。加工仍仅无颜色总量。
- 原片段仅允许减量或显式零删除，保留ID、颜色、执行方和月份。增加全部进入待分月/未分配；同色不得一边减旧量一边增加，以免抹掉旧归属。改色通过明确删除旧色并增加新色，不能自动认定颜色更名。
- 确认/锁定月的原行完整保护。新来源低于其贡献时阻断，须按既有权限另行重开；不能跨颜色补偿。原完成量、排单和执行方历史不动。
- 新版本只保留仍有行引用的原executorBasis，内容逐字不变；未使用basis从新版本移除，所有旧版本保持。
- 不改创建时交期/defaultMonth、报价/CCT/商业版本、已采用财务或冻结manifest。开放期财务需要另外显式同步，本动作不确认收入。

服务复用事务审计、durable rejected receipt和COMMIT未知核对；无自动重试或第二份API。严格客户端独立验证Source预览，旧move/match总量守恒断言不放宽。没有新增DOM、按钮、来源复核UI、导航、Browser仓储或真实Source范围。

合成持久化恢复夹具在原primary订单真实刷新100→120后，显式调用同一复核命令，不换SO、清库或覆盖旧计划。最终镜像/恢复、远端CI和正式部署是独立门槛；现有61104体验和其他资产保持。具体验收见[阶段](../tasks/active/closing-source-reconciliation-2026-10-27.md)。
