## 当前业务目标

- 仅成衣销售单价CNY与加工单价USD，分别产生**成衣销售产值**和**加工产值**；不同币种不相加，不自动换汇。加工产值包括内制及外发，切换显示范围时，明细与全年逐月汇总使用同一范围；显示开关不改账本。不能把未分配数量默认归为内制。
- 新SO创建时按成衣交期月份归属全部有效数量：合同类读取可信合同总成衣交期，加工类读取确认下单批次交期。缺交期保留待分月；缺价格/期间税率不阻止SO创建，金额保持未知，不补0或确认收入。
- “关账调整”支持部分数量或整单跨月调整，源月扣减与目标月增加必须同一事务；逐颜色/执行方和全单数量守恒。订单、排单、实际完成及关账分月是独立事实，调整不改变生产状态或完成量。
- 生产状态未制作/制作中/制作完成、全年12个月两项产值及内外发片段供调整参考，不按累计完成日期自动分月。显示范围限制可见明细和汇总；整单操作必须明确展示其包含的所有月份和执行方，不能悄悄只移动已筛选的一部分。
- 成衣公式和期间显式确认税率保持D162，不能预填13%；CNY工价先阻断加工金额，报价中心明确采用可信USD商业版本后才纳入。Quote/PV/CCT、订单商业版本和已冻结关账快照继续是既有金额依据，不复制成另一套可变价格。
- confirmed/locked期间不接收普通调月，源月也不能被绕过；先按原权限撤销确认或带原因重开。锁定历史、实际执行方及已完成量保持。
- 交期变化不静默改写已经确定的分月；数量/颜色依据变化需显式复核，不能把新增量自动摊入人工分月或把减量从历史扣走。

## Gate8G1已实现

`0047_order_closing_month_plans.sql`新增四张空表：plans保留创建时默认月份/交期；versions保留未定价数量分月；heads仅推进；commands保留原actor/request及终态。无历史回填、Browser导入、税率默认、价格复制或来源激活。旧0045/0046字节不改。

合同新增与加工批次首次消费在原SO创建事务内调用`initializeOrderClosingMonth`。重复接纳/消费返回原SO，不重新初始化；读取、启动或升级不补造旧订单计划。合同入口、批次消费及报价推送在CCT/Quote/SO锁之前取得同一`production-planning-write-v1`锁，内部调用可重入；避免建单持CCT、生产持全局锁、商业采用持SO形成三方环。默认月已确认/锁定时，SO仍创建，数量保留待分月。颜色明确且合计等于总量时按稳定颜色初始化，歧义/不完整/超预算时保留全单未匹配数量，不能猜颜色。

`quantity_state`为ready/unknown/unsupported。关账可调量当前限12整数位、6小数位，但原Source合法NUMERIC不受此限制：高精度或超范围总量原样保存，状态unsupported、数量行为空，调月明确409，绝不截断/舍入或回滚SO。总量可表示但颜色量不可表示时，保留全单uncolored量及原颜色证据，后续显式匹配。unknown不补0。

内部服务`month-plan-service.ts`：read、preview、execute、receipt；**本切片没有HTTP路由、React/provider或导航接线**。现有CLOSING_READ_PERMISSIONS与`closing.edit`复用，不新增隐式金额权限。读写fresh核对active/归档/当前RBAC，不信任调用方permissions。

调月只接受订单、当前版本、目标月、原因与整单/部分行数量；拒绝价格、币种、来源数量、颜色/执行方覆盖等额外字段。精确百万分之一数量用BigInt运算；每次动作保存全部颜色结果，SQL再次核对总量及颜色/执行方守恒。Source数量/颜色变化拒绝待复核，不直接改写计划；当前有效别名不能作为另一物理订单使用。

原actor/request锁、全局生产锁、head CAS、当前Source行锁和期间状态复核保护预览到执行的变化；稳定404/409/422拒绝也保存回执。版本、head、既有OperationLog和回执同事务。COMMIT未知保持unverified；原UUID/hash只读核对，重试同命令只回放，不追加第二版本。

命令PG jsonb文本16KiB、完整计划256KiB/2000行；部分操作最多100行。完整结果预算在预览和应用前检查，容量问题返回422及持久拒绝，不等数据库约束返回500。原0045有效归属并存时调月阻断，不能同时把两套数量当成有效结果。

历史引用盘点登记0047完整schema、plans/versions/heads及所有原命令（包括拒绝命令）；部分schema失败关闭，未知外键仍阻断。内部历史恢复检查保持，不恢复用户已取消的归一页面或执行权限。
