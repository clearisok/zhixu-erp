## 调整工作区

```text
订单 ...       未制作/制作中/制作完成（累计真实事实只读）
[部分数量] [整个订单]    目标月份 ...
原月份/颜色/执行方/可调数量 ...  本次调入数量 ...
原因 ...
调整前 → 调整后（源月减少、目标月增加、两项产值差异）
[取消] [预览] [确认调整]
```

全年参考在编辑时保持，订单列表可暂收起减少干扰；内容局部滚动、底部动作固定。整单明确包含该单所有月份/颜色/内外发片段，即使当前筛选隐藏了部分，也在预览中列出；切换范围/年份后旧预览失效。范围同时过滤明细和汇总，不改账本，未分配不默认内制。

仅两项金额，各自按售价/工价权限投影；无权显示“无金额权限”，不同币种不相加。多色按精确商业行，不平均；加工无成衣售价。调整不改生产状态、完成量、Quote/PV/CCT或工价；CNY工价提示去报价中心明确采用可信USD，不换币种标签。完成和成衣出货只参考，不自动确认收入。

源月/目标月confirmed或locked均阻断普通调月，须先原权限取消确认/带原因重开。历史、生产更正复核及锁定快照保护保持；不把更正的完成量静默摊到其他月。

原请求核对位于弹窗固定底部消息区：保存前先存原命令并读回；结果未知显示“核对原请求”，刷新只恢复不重发。明确unknown后原ID重试须用户点击确认；已知终态后才释放原缓存。账号/权限变化不能消费旧owner响应；预览/未决操作有离开提醒。
