## 用户决定与界面范围

用户批准的D121计划要求归一案件、完整引用核对和生产/财务独立复核，原身份/流水/价格保留；未授权真实归一。本阶段将已实现的后台工作区接入既有Server订单中心和Foundation Modal。没有新增主导航、生产路由或新主题。管理员在原案件详情读取完整组，明确选择有效订单（首次归一单root，纠正逐原订单选择），填写原因及独立恢复方案SHA256，预览并发布精确证据。不能自动决定root、伪造恢复摘要或因摘要存在就声称备份成功。

订单中心增加“归一岗位复核”入口，仅fresh可信管理员/生产/财务角色能打开；管理者、报价、物控、跟单无入口。复核列表可搜索、分页及包含历史；详情展示原/拟归属、完整声明引用、冻结外部计数、证据/恢复摘要、当前签名授权状态及历史分页。外部未覆盖仍为未知，不能批准；具体阻断原因可读，不将requiredReviews空数组说成无需复核。实际执行按钮始终未开放，本阶段只保存proof/review/audit。

签名岗位只能选当前授权类型，独立账号要求由后端再校验。财务签名说明按既有金额字段权限隐藏，不改变金额权限。证据变化后旧方案不能签名；撤权后清空已展示事实，不回退Browser。丢失成功响应保留原方案/请求，重试只一个proof/签名；未确认写结果时阻止关窗或换内容。关闭纯读取取消AbortSignal并清空详情，不让迟到旧响应覆盖新页面。
