## 4. 应保留的架构与工程设计

- **价格所有权清晰**：`server/confirmed-commercial-terms/confirmation-source.ts:7–13` 以 CCT 是否存在确定确认权威，空值不回退；`server/sales-orders/sale-adjustment-service.ts:79–101` 以订单事务追加商业版本和回执。改单不改另一单、报价 CCT 或产品方案，不需要再造价格账本。
- **来源与业务分离**：目录可查不自动生成 SO；失败保留成功观察与最近成功时间；共享目录证据保留逐次时间、分页和独立合同关联。此前样本证据体积下降 96.59%，应继续验证增长趋势，不删历史换空间。
- **权限在服务端生效**：角色编辑与用户管理共用保护锁，`server/auth/session.ts:81`、`team-access.ts:102`、`managed-roles.ts:45,66` 在登录/权限修改间串行化并撤销会话。复核后未把“改密码与登录竞态”列为已存在问题。自定义角色不能授予保留的管理员权限；金额权限独立。
- **生产与财务事实独立**：`server/production-scheduling/execution-preview.ts:25–58` 保护已有产出的执行归属；`server/closing/contract.ts:119–137` 使用精确十进制运算；关账的预览、回执、复核和冻结快照应保留。来源刷新不能重建人工产量或已锁定金额。
- **迁移前向且启动验证**：保留 `server/db/migration-status.ts` / `migration-runner.ts` 的历史校验及部署前显式迁移；不要改旧 SQL 文件、自动清库或由应用启动偷偷升级。

## 5. UI/UX 与性能建议

本轮主要是代码路径与既有用户反馈复核，没有新的浏览器交互计时或逐屏视觉验收；以下是产品建议，不冒称已经复现当前线上 UI 缺陷。

1. **订单/目录优先表达业务状态**：把“正式订单”“仅来源目录”“最近成功时间”“本次失败”“等待重试”分别展示，不能合成一个含糊的“已同步”。过期历史仍可查看，但不显示为本次零采购。优先级 P1，沿用现有字段和表格，成本小至中。
2. **单单刷新给出可核对结果**：正在采集、失败需核对、已完成都给出当前合同回执，不能仅依靠按钮转圈；暂停期间明确“需先处理来源异常”。沿用现有请求编号，不新建另一套任务系统。优先级 P1。
3. **路由卡顿先测再改**：`components/foundation/app-shell.tsx:108–117` 已有导航模块预加载。应在相同设备/网络记录冷、热切换的“点击到可用”、首接口耗时、资源体积，并记录 P50/P95；再决定拆包还是优化查询。未经测量，不能断言数据库、Cloudflare 或前端框架是根因。不要为提速缓存跨用户业务数据。优先级 P2。
4. **报价与关账逐步降低页面复杂度**：保留已认可的结构，优先拆出请求/错误/预览状态模型和独立表格区块；价格与历史读取口径保持统一。只有明确测量/使用问题时再提出布局变更。优先级 P3。

## 6. 工程流程、CI 成本与 AI 协作

三项必要 CI 已采用 PR 事件与手动运行、按 PR 取消过时运行、npm 缓存及 15/20/25 分钟限时；**没有发现 Push 与 PR 双触发问题**。证据：`.github/workflows/release-baseline.yml`、`first-team-access.yml`、`ainuoke-server-source.yml`。不应为“节省费用”再次建议已经存在的改动。

仍可改善的是共同编译/构建重复，以及 source 工作流一个长步骤前段失败导致后续模块没有结果。推荐先保留三个必须通过的检查名称与门槛，在后续独立小 PR 中抽取公共验证，再按改动范围调度模块；准备合并时仍跑完整必要验收。本轮不改变工作流或重跑已成功 CI。旧 `deploy-production.yml` 仅手动触发，仍指向 `zhixu-prod`/3000 与旧部署命名；它不是当前宁波 trial 发布路径，不能拿来完成这次升级。保留旧资产，后续先补明确用途/入口保护再决定退役，未验证其是否仍服务旧环境。

AI 开发的实际限制与改善方式：

| 来源 | 具体影响 | 改善措施 |
| --- | --- | --- |
| 多版本、多环境、阶段文档混排 | 反复确认代码、PR、镜像、staging 哪个已生效；本次传入旧 7bf3 路径也已不是有效仓库入口。 | 当前入口只保留一页状态，固定四元组：源码 SHA / 镜像身份 / 目标库 / 验收回执。旧记录归档并链接，不覆盖。 |
