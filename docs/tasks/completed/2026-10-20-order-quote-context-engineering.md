contract-source selection step. It opens the existing new route with a canonical
SO identity, reads a trusted nonmonetary context, and waits for an explicit
distribution-draft command. The ordinary no-context D102 one-click path, original
number allocator, defaults, writer and Editor remain. Source customer/brand names
are clues, never inferred master IDs. Only proven style, exact quantity and
garment delivery date are copied.

The 0033 forward migration saves one immutable creation reference alongside the
Quote, audit and actor/request receipt in the same transaction. This is not
commercial adoption, an order writer, a CCT link or a restriction on a Quote
serving several orders. No SO, procurement, production or commercial quantity is
changed. Processing consumption stays on its existing independent batch path.

Fresh grants, exact contract identity, effective attribution, lifecycle, current
commercial adoption and source fingerprint are checked again before commit.
Source mirror/link share locks last to COMMIT. Known semantic refusals have a
durable rejected receipt; unknown results keep their original request and use
GET reconciliation. Mount, refresh, History and late replies never issue another
automatic POST. Actual-session leases and layout cleanup reject A→B→A stale
successes and 401s before navigation or session invalidation.
